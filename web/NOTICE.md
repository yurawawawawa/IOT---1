# BuddyCheck — pemberitahuan dependensi

Kode aplikasi BuddyCheck dilisensikan menggunakan MIT; lihat `LICENSE`.

Library pihak ketiga tetap memiliki pemegang hak cipta dan ketentuan masing-masing:

- **MQTT.js 5.16.1**: klien MQTT JavaScript, disertakan di `web/vendor/mqtt.min.js`. Lisensi MIT tersedia di `web/vendor/MQTT-LICENSE.md`.
- **Eclipse Paho MQTT Python**: klien MQTT untuk detector dan edge Android. Paket dipasang melalui `requirements.txt` dengan lisensinya sendiri.
- **python-dotenv**: pembacaan konfigurasi environment; dipasang melalui `requirements.txt` dengan lisensinya sendiri.
- **Anton** dan **DM Sans**: font lokal dari Google Fonts, dilisensikan dengan SIL Open Font License. Lisensi disertakan di `web/fonts/ANTON-OFL.txt` dan `web/fonts/DM-SANS-OFL.txt`.
- Alat pengembangan dan dependensi transitif dicatat dalam `package.json` dan `package-lock.json`.

Pemberitahuan ini juga disertakan dalam paket halaman web BuddyCheck.
